# SportyFanz

Every Sport. Every Fan. Every Moment.

## Repository Structure

- frontend/ - Fan website and admin dashboard
- backend/ - API server and database operations

## Production Infrastructure

- Frontend: QServers
- Backend: Render
- Database: Neon PostgreSQL
- DNS: Cloudflare

## Development

Frontend and backend maintain separate package.json,
package-lock.json and Next.js configurations.

Private environment files must never be committed.
